
# Creative Rave — Portfolio

Welkom bij mijn portfolio website **Creative Rave**.

Op deze website laat ik mijn ontwikkeling, projecten en creatieve werk zien als (toekomstige) mediavormgever. De website geeft een overzicht van mijn werk op het gebied van grafisch ontwerp, fotografie, audiovisueel werk, animatie en een klein deel webdevelopment.

## Over de website

De website is door mijzelf ontworpen en gebouwd. Ik heb de website gemaakt om mijn werk te presenteren en tegelijkertijd mijn vaardigheden op het gebied van webdevelopment verder te ontwikkelen.

De website bevat onder andere:

* Mijn persoonlijke introductie
* Een overzicht van mijn projecten:

* Grafisch ontwerp
* Fotografie
* Audiovisueel en mixed-media werk
* Animatie

maar ook:
* Mijn ontwikkeling als mediavormgever
* Werk uit mijn stage bij RM-Sanitair
* Werk als content creator bij Borboleta Music
* Mijn eigen portfolio-website

## Technologieën

Voor deze website heb ik gebruikgemaakt van:
* HTML5
* CSS3
* YouTube embeds
* Responsive webdesign
* Git & GitHub

Tijdens het ontwikkelen heb ik veel gebruikgemaakt van online Youtube tutorials, google en feedback van mijn omgeving om mijn kennis van HTML, CSS en webdevelopment verder te ontwikkelen.

## Doel van de website
**Het portfolio heeft twee doelen.**

*/Voor mijn opleiding*/
De website vormt een overzicht van mijn ontwikkeling tijdens mijn opleiding Mediavormgever. Ik gebruik het portfolio om projecten, leerervaringen en mijn groei te presenteren.

*/Voor mijn toekomstige werk*/
Naast mijn schoolportfolio wil ik Creative Rave blijven gebruiken als professioneel portfolio. Nieuwe projecten, opdrachten en ervaringen kunnen hier in de toekomst aan worden toegevoegd.
Op deze manier groeit de website mee met mijn ontwikkeling als vormgever.
Hierdoor krijg je een beter beeld van waar ik gestart ben en waar ik nu sta sinds heden.
